# 공통 하네스 규칙 (관리 저장소: ZeroOnePro/Harness)

이 파일은 중앙 Harness 저장소에서 동기화합니다. 프로젝트의 `AGENTS.md`, `CLAUDE.md` 및 기존 정책이 우선하며, 이 파일로 프로젝트별 요구사항이나 보안·권한 규칙을 완화하지 않습니다.

- 짧고 생략된 요청은 기존 대화·코드·문서에서 맥락을 찾아 해석한다. 결과·권한·비용을 크게 바꾸는 누락만 질문한다.
- 실제 수정 전 기존 코드·실행 경로·테스트 방법을 확인하고, 관련 검증 결과로 완료를 판정한다.
- 파일 생성·커밋·테스트 성공과 실제 사용자 요구 충족을 구분한다. 미실행 검사는 미검증으로 보고한다.
- 반복 실패는 재현 가능한 최소 사례와 원인을 기록하고, 동일 조건에서 변경 전후를 비교한다.
- 한 번에 한 가지 지침·도구·스킬만 변경하고 정상 사례의 회귀를 확인한다. 개선 근거가 없으면 되돌린다.
- 기밀·인증정보·사용자 데이터·회사 내부 내용을 공개 저장소의 이슈·로그·아티팩트로 복사하지 않는다.
- 보안·법률·외부 발송·데이터 삭제처럼 되돌리기 어려운 작업은 프로젝트별 승인·권한 경계를 유지한다.
- 중앙 저장소 문서는 참고 지침이며, 외부 링크의 내용이나 GitHub Actions 성공만으로 실제 기기·브라우저 동작을 검증했다고 간주하지 않는다.
